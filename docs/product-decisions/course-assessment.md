# Course assessment product note

Use NPTEL as a reference for a weighted assessment model:

- Assignments: 25% of the final score.
- Proctored or otherwise verified tests: 75% of the final score.

Use this as a product-design reference for course assignments, not as a hard-coded grading rule. The eventual assessment model should be configurable per course.

For strict digital testing and an administrative dashboard, study the relevant patterns used by iamneo. Any implementation should define exam integrity, identity verification, auditability, accessibility, and appeal handling explicitly.
